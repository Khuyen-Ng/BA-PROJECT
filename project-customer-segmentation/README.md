# Customer Segmentation

Mục tiêu: Phân khúc khách hàng dựa trên hành vi mua hàng để tối ưu hóa chiến lược bán hàng.

Nội dung dự án:

- Thu thập và tiền xử lý dữ liệu khách hàng.
- Áp dụng thuật toán K-Means để nhóm khách hàng.
- Phân tích đặc điểm từng nhóm và đề xuất chiến lược tiếp cận.

File chính:

- `src/customer_segmentation.py`

Hướng dẫn chạy:

1. Tạo môi trường ảo Python.
2. Cài đặt `requirements.txt`.
3. Chạy `python src/customer_segmentation.py`.
