# Sales Analysis Dashboard

Mục tiêu: Phân tích doanh số bán hàng để hỗ trợ ra quyết định bán hàng và marketing.

Nội dung dự án:

- Tập trung vào dữ liệu doanh số bằng Python và Pandas.
- Tính toán các chỉ số KPI chính: tổng doanh thu, doanh thu theo sản phẩm, doanh thu theo khu vực.
- Trực quan hóa xu hướng doanh thu và phân chia doanh số.

File chính:

- `src/sales_analysis.py`

Hướng dẫn chạy:

1. Tạo môi trường ảo Python.
2. Cài đặt `requirements.txt`.
3. Chạy `python src/sales_analysis.py`.
