# Market Forecasting

Mục tiêu: Dự báo doanh thu và xu hướng thị trường bằng Python.

Nội dung dự án:

- Tạo dữ liệu thị trường giả lập.
- Phân tích xu hướng và seasonality.
- Sử dụng mô hình đơn giản để dự báo doanh thu trong tương lai.

File chính:

- `src/market_forecasting.py`

Hướng dẫn chạy:

1. Tạo môi trường ảo Python.
2. Cài đặt `requirements.txt`.
3. Chạy `python src/market_forecasting.py`.
